# Lulo OS session asset license inventory

Almost every non-code asset the session and app packages ship is original
Lulo OS (rmac) work, licensed under the MIT License in the repository root.
The one exception is the Lucide icon set listed below. Nothing is copied from
Apple. This was checked on 2026-10-05 against the git history and file
headers of every shipped SVG, PNG, JPEG and WAV file.

| Assets | Source | License |
|---|---|---|
| Wallpapers, `packaging/rmac-session/wallpapers/` (48 files) | Generated by `scripts/build-wallpapers.py` from original procedural designs | MIT |
| System sounds, `assets/sounds/` (15 files) | Synthesised by `assets/sounds/gen/make_sounds.py` | MIT |
| Cursor theme, `assets/cursors/` (35 files) | Original theme built by `scripts/build-cursors.py` | MIT |
| Icons, `assets/icons/` and the app and shell `assets/icons/` folders | Original artwork drawn for Lulo OS in `design-lab/`, built by `scripts/build-icons.py` | MIT |
| Brand marks, `assets/brand/` | Original Lulo OS mark and lockup | MIT |
| Greeter artwork, `packaging/rmac-session/greeter/` | Original artwork | MIT |
| Shell symbols, `shell/assets/symbols/`, `shell/assets/menu/` and the other `shell/assets/` folders | Original 16 px stroke symbols drawn for Lulo OS | MIT |
| Lucide icons: 25 in `crates/finder/assets/`, 34 in `crates/system-settings/assets/`, and those in `vendor/gpui-component` | [Lucide](https://lucide.dev), unmodified, each with its `@license lucide-static … ISC` header | ISC (Lucide contributors) |

No Apple artwork, logos, fonts, sounds or other proprietary assets are
included. Fonts come from Ubuntu's own packages (for example Inter and Noto),
under their upstream licenses, and are not redistributed by these packages.

Provenance checked by the maintainers on 2026-10-05 (git history plus a scan of file headers for Lucide, Apple and SF Symbols markers).
