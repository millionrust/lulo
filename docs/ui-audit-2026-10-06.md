# UI audit 2026-10-06

An automatic pass that compares macOS 26.2 with Lulo, run so the owner doesn't have to report UI differences by hand. The findings are rows `UIA-01`–`UIA-26` in [parity.md](parity.md#ui-audit-2026-10-06), together with the correction to `CLOCK-05`. No images are committed. Captures stay on the machines that took them.

## Method

- **Mac:** macOS 26.2 at 1470×956 pt. Each app ran in Light and Dark, and the original appearance was restored afterwards.
  - The script captured each window with `screencapture -l` and each open menu with `screencapture -R`.
  - It read AX geometry for windows, menus, menu items and controls.
  - Temporary files went into a sandbox folder. No private windows were captured: Notes, Mail and Calendar were recorded for their menus and Settings only.
  - Every sheet was cancelled.
- **Lulo:** installed build 0.9.0~beta.1-38 (`bb6b6b06`). Its `.deb` files were extracted privately, not installed.
  - The apps ran in a private nested niri at 1280×800, with the shipped top bar and Dock, inside `scripts/behavior/run_lulo.py`'s headless Sway.
  - The appearance was set with `$XDG_CONFIG_HOME/rmac/theme.json` (`color_scheme`).
  - Geometry came from the private AT-SPI bus.
- **Compared:**
  - 13 apps, plus the top bar, the Lulo/Apple menu, Control Centre, Notification Centre, Spotlight, Apps and the Dock;
  - every menu-bar menu, the main context menus, the Settings panes, the Save sheet, Get Info, New Folder and empty states.
- **Method of comparison:** the captures were inspected by eye, and the measurements were diffed by script: window sizes, menu widths, row heights and menu items.

- 12-hour time in the top bar: the owner's Mac uses 12-hour time.
