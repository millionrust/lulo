# Terminal Help

Terminal gives you a shell prompt on Lulo OS.

- ⌘F Find in the current scrollback, ⌘G/⇧⌘G Find Next/Previous
- ⌘C Copy, ⌘V Paste, ⌘A Select All
- ⌘H Hide Terminal, ⌘M Minimise the current window, ⌘Q Quit

See `docs/parity.md` in the Lulo OS source for the current list of
known differences from macOS Terminal.
