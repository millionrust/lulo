What this is

Every rmac surface, drawn in HTML and CSS at the measured macOS 27 values. It is a ruler, not a runtime — rmac still ships as Rust and GPUI. The point is the loop: changing a number here takes one second, changing it in Rust takes ten minutes. Get it right here, then port it.

How the agent uses it

  1. Open a page. Read the table at the bottom of each section — it maps every CSS value to its crates/rmac-design field.
  2. Port those values. Never retype a number by eye; copy it from the table.
  3. Rebuild rmac, run scripts/linux/capture-shell-evidence.sh on the reference PC.
  4. Put the rmac capture and this page side by side. List what still differs, in pixels.
  5. Fix the top five. Repeat.

All tokens live in one place: design-lab/tokens.css. That file is the mirror of crates/rmac-design. If the two ever disagree, the measured captures in docs/measured-colors-2026-09-19.md and docs/reference-captures-2026-09-18.md decide.

Honest limits of this lab

CSS backdrop-filter is not niri's ext-background-effect; blur radii transfer approximately, not exactly. The squircle here is a CSS radius approximation, while the icons themselves are true superellipses. Font rendering differs between WebKit and GPUI, so trust the metrics from this lab and the colours from the measured docs — and always confirm against a real capture from the reference PC.
