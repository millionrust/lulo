# Lulo 0.9.0 Beta 3 (Ubuntu) + Windows Preview

Lulo is a desktop that looks and works like macOS 26, built to run well on everyday and low-spec PCs: a menu bar, a Dock, Spotlight, Mission Control, Control Centre and Notification Centre, and its own apps. Beta 3 follows Beta 2 (14 October).

- **Lulo OS on Ubuntu is the beta.**
- **Windows is an early preview.** Lulo runs on top of Windows 11. Expect rough edges. The installer is not signed (see below).
- **New: a Lulo OS USB stick image.** For the first time this release has a bootable `.iso`: try Lulo OS live from a USB stick without touching your PC, then install it if you like it.

## Install

- **Lulo OS from USB (new):** download `lulo-os-0.9.0-beta.3-amd64.iso` (about 1.7 GB) below. Write it to a USB stick of 4 GB or more with [balenaEtcher](https://etcher.balena.io/) or Rufus (DD mode), boot the PC from the stick, and Lulo OS starts live. **Install Lulo OS** in the Dock installs it to the disk (erase the disk, or install alongside Windows or Ubuntu). It works with Secure Boot on, on UEFI and older BIOS PCs. The ISO is built and boot-tested in a virtual machine after this release is published, so it can appear on this page an hour or two after the other files.
- **Next to Ubuntu 26.04 (64-bit PC):** open a terminal and run
  `curl -fsSL https://github.com/millionrust/lulo/releases/download/v0.9.0-beta.3/install.sh | sh`
  then log out and choose **Lulo OS** on the login screen. Full steps, and how to remove it: [Install on Ubuntu](https://github.com/millionrust/lulo/blob/dev/docs/install-ubuntu.md). If you installed Beta 2 this way, run the same line to update.
- **Windows 11 (64-bit):** download `Lulo-Setup-0.9.0-beta.3-x64.msi` below and open it. No administrator password is needed, and it updates Beta 2 in place. Full steps, and how to remove it: [Install on Windows](https://github.com/millionrust/lulo/blob/dev/docs/install-windows.md).

**Windows will warn you about the installer.** The MSI is not code-signed (signing costs money, and this is a free project), so Microsoft Defender SmartScreen shows "Windows protected your PC". Click **More info**, then **Run anyway**. Its SHA-256 is listed in `SHA256SUMS` below.

## What's new since Beta 2

- **Stage Manager** (off by default): turn it on in Control Centre or System Settings ▸ Desktop & Dock.
- **Dock:** minimised windows pour into their own tile with the Genie or Scale effect, app menus list recent documents, the Files tile offers Find…, Go to Folder… and Connect to Server…, and the System Settings tile lists its panes.
- **Control Centre and Notification Centre:** Edit Controls, round controls in macOS order (Low Power, Screen Mirroring, Dark Mode, Screenshot), Clear All, and banner Options menus.
- **Menu bar:** Control-F8 moves the keyboard to the status menus; the battery shows a bolt while charging and the time left.
- **Window tiling:** drop a window at a screen edge to fill that half.
- **Notes:** rich text, tags and the tag browser. **Mail:** Send Later, Remind Me, mailbox and rules sheets, VIPs. **Files** and **Preview:** many more Mac menu items and sheets.
- **Windows preview:** Mission Control, App Exposé and hot corners; minimised windows in the Dock with Genie; Force Quit (Ctrl+Alt+Esc); screenshots with the Mac-style capture toolbar; the volume panel; Dock badges and bouncing; Ctrl+Q quits the front app; Spotlight finds files through Windows Search; smoother scrolling and faster app start-up. Media Player now ships with its playback library (libmpv), so it plays video out of the box.
- **Security:** rustls-webpki updated to 0.103.16 for RUSTSEC-2026-0382.

## Known limitations

- **Ubuntu:** tested on Intel graphics only; NVIDIA and AMD desktops are untested. Lulo OS does not update itself yet: run the next release's install line. Stage Manager is off by default and still being polished. Screen recording is not in this release, and the emoji and symbols picker comes next. Files does not browse network shares or phones yet. Some apps take one to two seconds to open on a slow PC.
- **USB image:** needs a GPU with a normal graphics driver; on a plain framebuffer (`nomodeset`, some virtual machines) the Lulo session starts but stays blank. NVIDIA's own driver is not on the image (the open driver works; you can add NVIDIA's after installing).
- **Windows:** Bluetooth connects only audio devices and has no "discoverable" switch. Printing, spelling underlines and Software Update are not there yet, and several System Settings panes are left out (Network, Notifications, Accessibility and others). To update, install the next release's MSI.
- **Both:** Mail's Google and Microsoft sign-in has not been tested against real accounts. Apple-only services (iCloud, AirDrop, Time Machine, Apple accounts) are left out on purpose.

The full list is in [Known limitations](https://github.com/millionrust/lulo/blob/dev/docs/known-limitations.md).

## Files

- `lulo-os-0.9.0-beta.3-amd64.iso` and its `.sha256`: the Lulo OS USB image (added after the release by its own build).
- `install.sh`, `uninstall.sh`: the one-command Ubuntu installer and remover.
- `rmac-apps_*.deb`, `rmac-session_*.deb`, `niri_*.deb`, `xwayland-satellite_*.deb`: the Ubuntu packages.
- `Lulo-Setup-0.9.0-beta.3-x64.msi`: the Windows installer.
- `SHA256SUMS`: checksums of the release's files; every file has a GitHub build-provenance attestation.
- Source packages, `apt-inputs-v0.9.0-beta.3.tar` and the SBOMs are for packagers and auditors.
