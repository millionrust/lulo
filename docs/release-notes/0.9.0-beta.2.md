# Lulo 0.9.0 Beta 2 (Ubuntu) + Windows Preview

This is the first public beta of Lulo, for Ubuntu and Windows. Lulo is a desktop that looks and works like macOS 26, built to run well on everyday and low-spec PCs. It has a menu bar, a Dock, Spotlight, Mission Control, Control Centre and Notification Centre, and its own apps.

- **Ubuntu (Lulo OS) is the beta.** It installs next to Ubuntu 26.04 and adds a "Lulo OS" session to the login screen. Ubuntu stays installed, so you can always go back.
- **Windows is an early preview.** Lulo runs on top of Windows 11: its own menu bar, Dock and Spotlight over the Windows desktop, and the Lulo apps as normal Windows programs. Expect rough edges. The installer is not signed (see below).

Beta 1 (`v0.9.0-beta.1`) was an internal build that never went to testers, so this is the first release most people will see.

## Install

- **Ubuntu 26.04 (64-bit PC):** open a terminal and run
  `curl -fsSL https://github.com/millionrust/lulo/releases/download/v0.9.0-beta.2/install.sh | sh`
  then log out and choose **Lulo OS** on the login screen. Full steps, and how to remove it: [Install on Ubuntu](https://github.com/millionrust/lulo/blob/dev/docs/install-ubuntu.md).
- **Windows 11 (64-bit):** download `Lulo-Setup-0.9.0-beta.2-x64.msi` below and open it. No administrator password is needed. Full steps, and how to remove it: [Install on Windows](https://github.com/millionrust/lulo/blob/dev/docs/install-windows.md).

**Windows will warn you about the installer.** The MSI is not code-signed (signing costs money, and this is a free project), so Microsoft Defender SmartScreen shows "Windows protected your PC". Click **More info**, then **Run anyway**. You can check the file first: its SHA-256 is listed in `SHA256SUMS` below.

## What's new since Beta 1

- **Faster everywhere.** Apps draw their first window sooner (GPU set-up and font loading moved off the start-up path), Spotlight, Control Centre, Notification Centre, Launchpad and the App Switcher open in about 25–30 ms, the Dock is there at login, and big folders scroll smoothly in Files. Idle apps use almost no CPU.
- **Touchscreens (Ubuntu):** tap to click, double-tap, rest a finger to right-click, swipe to scroll with the content following your finger (and gliding on), drag title bars, sliders, Dock tiles and files, and scroll or pinch with two fingers.
- **Security fix:** the TLS library used by Mail, Calendar and accounts (rustls) is updated to 0.23.46 for RUSTSEC-2026-0346 to 0349.
- **Dock:** drag an app onto the Dock to keep it there, drag to rearrange, folder stacks, and the Mac's blurred shelf.
- **Context menus, window corners and shadows** now match the Mac much more closely, after an audit of every Mac menu, dialog and pane against Lulo.
- **System Settings:** many panes and rows brought in line with macOS 26.
- **Files, Notes, Preview, Text Editor and Terminal:** dozens of missing menu items and behaviours added.
- **Lulo Intelligence (Ubuntu, optional, off by default):** turn it on in System Settings ▸ Lulo Intelligence to get Writing Tools, plain-language requests in Spotlight ("turn on dark mode", "set a timer") and "Talk to Lulo" voice commands. A small model is downloaded once and then runs on your own PC; your text and voice never leave it. It costs nothing while it is off.
- **Windows preview:** Calculator, Notes, Text Editor, Preview, Clock, Weather, Terminal, Files, System Settings, System Monitor, Mail, Calendar, Media Player and Archive Utility, plus the Lulo layer (menu bar, Dock, Spotlight with Alt+Space, App Switcher). Shortcuts use Ctrl where the Mac uses Cmd.

## Known limitations

- **Ubuntu:** tested on Intel graphics only; NVIDIA and AMD desktops are untested. Lulo does not update itself in this beta: to update, run the install command of the next release. Some apps still take 0.6–1.8 s to open on a slow laptop. Files does not browse network shares or phones yet (Ubuntu's own Files stays installed for that). Screen-reader users cannot yet type into search fields through assistive technology.
- **Windows:** Media Player needs `libmpv-2.dll`, which is not bundled yet, so it says it needs libmpv. Bluetooth connects only audio devices, and there is no "discoverable" switch. Printing, spelling underlines and Software Update are not there yet, and several System Settings panes are left out (Network, Notifications, Accessibility and others). To update, install the next release's MSI over this one.
- **Both:** Mail's Google and Microsoft sign-in has not been tested against real provider accounts. Apple-only services (iCloud, AirDrop, Time Machine, Apple accounts) are left out on purpose.

The full list is in [Known limitations](https://github.com/millionrust/lulo/blob/dev/docs/known-limitations.md).

## Files

- `install.sh`, `uninstall.sh`: the one-command Ubuntu installer and remover for this release.
- `rmac-apps_*.deb`, `rmac-session_*.deb`, `niri_*.deb`, `xwayland-satellite_*.deb`: the Ubuntu packages `install.sh` installs.
- `Lulo-Setup-0.9.0-beta.2-x64.msi`: the Windows installer.
- `SHA256SUMS`: checksums of every file. Every file also has a GitHub build-provenance attestation.
- Source packages, `apt-inputs-v0.9.0-beta.2.tar` and the SBOMs (`rmac-sbom-v0.9.0-beta.2.tar.gz`, `*.cdx.json`) are for packagers and auditors.
