Lulo OS Beta 1

The first public Beta of Lulo OS, a Mac-feel desktop for everyday PCs,
built on Ubuntu 26.04 and niri.

- A macOS-style desktop: menu bar with app menus, Dock with folder stacks,
  Mission Control, Spotlight, Control Center and Notification Center.
- Touch input: tap, double-tap, hold for a context menu, drag, and natural
  momentum scrolling on a touchscreen.
- Built-in apps: Files, Terminal, Notes, Text Editor, Preview, Calculator,
  System Monitor, Clock, Weather, Media Player, Archive Utility and System
  Settings, every pane backed by a real Linux service.
- New Calendar and Mail apps. Add Google, Microsoft, iCloud or Yahoo in
  System Settings > Internet Accounts; reminders and invitations included.
- Rich text in Text Editor (bold, colours, lists, RTF), locked notes in
  Notes with real encryption, and image editing in Preview.
- Mac keyboard shortcuts, ⌘M minimise for every app, keyboard access to the
  menu bar (⌃F2) and the Dock (⌃F3), and window tiling.
- Files, Terminal, Notes, Control Center and Notification Center now expose
  real accessible content to screen readers. Typing into a search or rename
  field over assistive technology isn't supported yet -- an upstream
  limitation, not an app bug.
- Software Update in System Settings, with updates installed at restart.

This is an early-access Beta, not a finished daily driver: expect rough
edges, no NVIDIA testing yet, and no in-place updates. Known issues are
listed in docs/known-limitations.md.
