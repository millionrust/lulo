# Text Editor Help

Text Editor is Lulo's plain-text editor (the TextEdit equivalent).

- ⌘F Find, ⌥⌘F Find and Replace, ⌘G/⇧⌘G Find Next/Previous
- ⌘Z/⇧⌘Z Undo/Redo, ⌘X/⌘C/⌘V Cut/Copy/Paste, ⌘A Select All
- ⌘H Hide Text Editor, ⌘M Minimise the current window, ⌘Q Quit

See `docs/parity.md` in the Lulo OS source for the current list of
known differences from macOS TextEdit.
