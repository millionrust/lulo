# Lulo OS 0.9.0-beta.1

Released 2026-09-24. This is the first public Beta of Lulo OS: a
GitHub Release with `.deb` packages you install by hand. There is no signed
APT repository yet, so there is no in-place update path for this release
either -- see "What comes after this Beta" below.

Read this together with [Known limitations](../known-limitations.md) before
you install. If you want the release-engineering detail instead of the
user-facing summary, see [CHANGELOG.md](../../CHANGELOG.md) and
[docs/beta-checklist.md](../beta-checklist.md).

## Who this is for

People comfortable running an early Linux desktop on a spare or disposable
machine, who want to try a Mac-feel session on Ubuntu 26.04 and report back
what breaks. This is not yet a daily driver, and it is not a replacement for
your normal desktop -- Ubuntu/GNOME stays installed and selectable at the
login screen the whole time.

## What's in this Beta

**Desktop and Dock:** a menu bar, Dock, wallpaper, and window chrome drawn to
match macOS 26; Mission Control, App Exposé, and Show Desktop with Spaces and
hot corners; screenshots and clipboard history; a lock screen, login window,
and a first-login Setup Assistant.

**Menu Bar and Control Centre:** Control Center and Notification Center as
real popovers, with Wi-Fi, Bluetooth, sound, and battery wired to
NetworkManager, BlueZ, PipeWire, and UPower; Mac-style keyboard shortcuts
(⌘C, ⌘V, and the rest) working across every app.

**Spotlight:** app and file search, calculator-style answers (sums, units,
currency, city times, definitions), an Actions view, and a Clipboard view.

**Apps:** Files, Terminal, Notes, Text Editor, System Monitor, System
Settings, Calculator, Clock, Weather, Media Player, Preview, and Archive
Utility. Files can copy, move, rename, trash (with Undo), and preview; its
clipboard now interoperates with other Wayland file managers. Terminal has a
real PTY with resize, scrollback, selection, and tabs. System Settings'
panes are backed by real Linux services, not placeholders -- see
[docs/settings-backend-audit.md](../settings-backend-audit.md).

**Reliability:** a session safe mode that starts a plain niri session for one
login after a crash loop and explains itself, so a single broken component
no longer strands you; several places that used to silently drop a failed
save now report it.

**Brand:** the project is now called Lulo OS. The login session, About
windows, system menus, and documentation all say Lulo OS. The code,
packages, and D-Bus names underneath still say `rmac` -- that rename is
tracked in `todo.md` and lands in later releases without affecting your data.

## Known limitations

The full list is [Known limitations](../known-limitations.md); the ones most
likely to affect you in this Beta:

- **Screen reader and keyboard coverage is uneven.** The Dock and Spotlight
  are keyboard- and Orca-reachable. Terminal's and Notes' own content areas
  (the terminal grid, the note list and editor) are not yet exposed to
  assistive technology at all -- you can open and quit both apps with a
  keyboard, but you cannot type into or read their content with a screen
  reader on this build.
- **Files has no accessible file list.** Toolbar buttons work with a screen
  reader; individual files, folders, and the sidebar do not appear in the
  accessibility tree yet.
- **No in-place updates.** This Beta doesn't check for or install updates
  over APT. A later release replaces it the same way you installed it: by
  hand.
- **The top-bar mark is still a placeholder glyph**, not final Lulo artwork.
- Lulo OS does not clone Apple's iCloud, AirDrop, Time Machine, or other
  proprietary services, and System Settings only exposes controls that a
  real Linux backend can support.

## How to install

You need a spare or disposable machine (or a VM) running **Ubuntu 26.04** on
**amd64 or arm64**, with your normal Ubuntu/GNOME session already working.
Do not install this on your only machine, and do not put real data in the
account you test with yet.

1. Open this release on GitHub and download `SHA256SUMS`, `rmac-apps_*.deb`,
   and `rmac-session_*.deb` (and `rmac-archive-keyring_*.deb`, if it's
   attached -- it prepares the machine for the signed APT repository that
   comes later, but isn't required to run Lulo OS today).
2. Verify what you downloaded before installing it:

   ```sh
   sha256sum --check SHA256SUMS --ignore-missing
   ```

   You can also verify this release's build provenance attestation with the
   GitHub CLI: `gh attestation verify rmac-apps_*.deb --owner millionrust`
   (repeat for each `.deb`).
3. Install the packages and let `apt` resolve their dependencies from your
   normal Ubuntu repositories:

   ```sh
   sudo apt install ./rmac-apps_*.deb ./rmac-session_*.deb
   ```

4. Log out, and at the login screen choose the **Lulo OS** session instead
   of Ubuntu. Your Ubuntu/GNOME session is untouched and still selectable
   every time you log in.

Full detail, including troubleshooting and a scripted native-package path,
is in [docs/install.md](../install.md).

## How to go back to Ubuntu

Nothing about installing Lulo OS changes your default session, so you can
switch back at any time:

- **For one login:** at the login screen, choose **Ubuntu** (or your
  distribution's default GNOME session) instead of **Lulo OS**. No
  uninstall needed.
- **To remove Lulo OS entirely:**

  ```sh
  sudo apt purge rmac-session rmac-apps rmac-archive-keyring
  ```

- **If Lulo OS won't start:** it drops into a one-login safe mode after a
  crash loop and tells you which component failed. See
  [Troubleshooting and recovery](../troubleshooting.md) for that and for
  exporting data before you remove anything.

## What comes after this Beta

A signed APT repository on GitHub Pages, so installs and updates go through
`apt`/PackageKit instead of downloading `.deb` files by hand. That needs the
owner's decision on who holds the archive signing key, plus a real Debian
source package for `rmac` -- both tracked in
[docs/release-process.md](../release-process.md). Until then, each new
release is a new GitHub Release you install the same way as this one.
