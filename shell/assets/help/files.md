# Files Help

Files is Lulo's file manager (the Finder equivalent).

- ⌘F Find, ⌘A Select All, ⌘X/⌘C/⌘V Cut/Copy/Paste
- ⌘Z Undo the last file operation
- ⌘H Hide Files, ⌘M Minimise the current window
- The Bin (Trash) holds deleted items until it is emptied

See `docs/parity.md` in the Lulo OS source for the current list of
known differences from macOS Finder.
