# Notes Help

Notes keeps short plain-text notes.

- ⌘F Find in the current note
- ⌘Z/⇧⌘Z Undo/Redo, ⌘X/⌘C/⌘V Cut/Copy/Paste, ⌘A Select All
- ⌘H Hide Notes, ⌘M Minimise the current window, ⌘Q Quit

See `docs/parity.md` in the Lulo OS source for the current list of
known differences from macOS Notes.
